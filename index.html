🚀 Le Projet Final

Projet de fin de formation : Progiciel de Gestion Intégré (PGI) web.

PGI Pro - Progiciel de Gestion Intégré

Application web locale permettant la gestion intégrée d'une PME : stocks, achats, ventes et ressources humaines.

📋 Description : Système de gestion intégré développé en HTML, CSS et JavaScript pur, fonctionnant entièrement côté client avec stockage local des données.

💻 Technologies utilisées :

  • HTML5 / CSS3
  • JavaScript (ES6)
  • LocalStorage / SessionStorage
  • Architecture front-end 100% locale

🎯 Objectifs :

  • Centraliser la gestion des opérations d'une entreprise
  • Gérer les stocks, achats, ventes et RH
  • Système de rôles (Administrateur / Employé)
  • Tableau de bord avec indicateurs clés
